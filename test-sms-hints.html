MeMark SMS Categorization

✓ Working

Your MeMark now automatically understands and categorizes messages you send via SMS. The AI analyzes each message, extracts important details, and organizes it into smart folders.

How It Works

  • Every message is automatically parsed and understood by AI
  • Links are extracted and categorized by domain (x.com, youtube.com, etc.)
  • Content is categorized by type (Education, Business, Technology, etc.)
  • Smart folders are automatically created and organized
  • You can add hints to guide the categorization

SMS Hint Examples

Example 1: Basic Link
https://x.com/techcrunch/status/123456789
Folders Created: x.com → Technology → Link
AI Analysis: Automatic title, summary, and tags
Example 2: With Category Hint
https://youtube.com/watch?v=abc123 place in education
Category Hint: Education
Folders: youtube.com → Education
Example 3: With Priority
Check this article: https://example.com/article important place in business
Priority: High
Category: Business
Example 4: With Custom Note
https://github.com/example/repo note: Review this for the new project place in technology
User Note: Review this for the new project
Category: Technology
Example 5: Natural Language
Great cooking tutorial: https://youtube.com/watch?v=xyz This is for food recipes
Detected Category: Food
Note: AI detects "cooking" and "recipes"

Supported Category Hints

  • Education: learning, study, course, tutorial
  • Business: work, career, professional
  • Technology: tech, programming, coding, dev
  • Health: fitness, wellness, medical
  • Entertainment: fun, movie, show, game
  • News: current events, politics
  • Science: research, study
  • Sports: athletic, exercise
  • Travel: vacation, trip
  • Food: cooking, recipe, restaurant
Pro Tip:

You don't need to use hints every time! The AI is smart enough to categorize most content automatically. Use hints only when you want to override the AI's decision or add specific context.

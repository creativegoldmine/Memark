Test and verify password reset functionality

Step 1: Send Password Reset Email

Step 2: Check Configuration

Instructions

  1. Enter your email address and click "Send Reset Email"
  2. Check your email inbox for the password reset link
  3. Click the link in the email - it should redirect to http://localhost:3000/reset-password
  4. If you see "Invalid Link", the redirect URLs need to be configured in Supabase
⚠️ Important: If the password reset link shows "Invalid Link", you need to configure the redirect URLs in your Supabase dashboard:

1. Go to Authentication → URL Configuration
2. Set Site URL to: http://localhost:3000
3. Add to Redirect URLs: http://localhost:3000/**

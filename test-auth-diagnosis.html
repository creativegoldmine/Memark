⚠️ Common Issues

Issue: "Invalid Link" error
Cause: URL mismatch or expired token (1 hour expiry)
Fix: Request a new reset link from the same URL

Issue: Link doesn't work
Cause: Browser cache or session conflicts
Fix: Try in an incognito/private window

Issue: Email not received
Cause: Email in spam or Supabase email rate limits
Fix: Check spam folder, wait 60 seconds between attempts
